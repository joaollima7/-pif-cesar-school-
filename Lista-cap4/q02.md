a) A mensagem impressa no console será "Opção B". Justificativa: a variável x vale 15, o que torna a primeira condição (x > 10) verdadeira. O fluxo entra no primeiro if e avalia a segunda condição (y > 10). Como y vale 5, essa segunda condição é falsa. Devido à regra do "dangling else" (o else sem chaves associa-se sempre ao if mais próximo semanticamente na mesma estrutura de aninhamento), o else pertence ao segundo if (if (y > 10)). Portanto, o bloco do else é executado, exibindo "Opção B".

b) A regra oficial da Linguagem C para associar uma cláusula else a um comando if em códigos sem chaves de bloco é a regra do "dangling else" (else pendente): um else é sempre associado ao comando if aberto mais recente que ainda não possui um else associado, independentemente da indentação visual do código.
