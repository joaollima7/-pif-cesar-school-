Ocorreu mais de uma impressão devido ao efeito fall-through. Como codigo vale 2, a execução entra no case 2 e imprime "Prata". Como não há um break, a execução continua direto para o case 3, imprimindo também "Ouro".

b) O break serve para encerrar o switch imediatamente. O fenômeno que ocorre quando ele é omitido é chamado de fall-through, fazendo o fluxo continuar descendo para os próximos blocos.

c) Apenas tipos inteiros (como int, char) ou enumerações são permitidos. Não é permitido usar float ou double, pois a linguagem exige tipos integrais para comparações exatas.
