a) O efeito prático de escrever if (x = 0) em vez de if (x == 0) é que o operador = realiza uma atribuição e não uma comparação. Em vez de testar se x é igual a zero, a variável x recebe o valor 0. Como o resultado da expressão de atribuição é o valor atribuído (0), o C o avalia como falso, fazendo com que o bloco de código associado ao if não seja executado

b) A Linguagem C não possui um tipo booleano nativo clássico (em versões mais antigas), interpretando qualquer valor numérico (inteiro ou real) da seguinte forma: o valor numérico 0 é sempre interpretado como "falso", enquanto qualquer valor diferente de zero (seja positivo ou negativo) é interpretado como "verdadeiro".

c) A instrução if (x = -5) terá o seu bloco de código executado. Justificativa baseada no padrão ANSI C: o operador = atribui o valor -5 à variável x. Como a expressão retorna o valor atribuído (-5) e o padrão ANSI C dita que qualquer número diferente de zero é considerado verdadeiro, a condição é avaliada como verdadeira, executando o bloco de código
