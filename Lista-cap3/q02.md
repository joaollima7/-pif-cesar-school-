a) A variável soma foi criada dentro do for. Assim que o ciclo acaba, ela "morre" e desaparece. O printf está lá fora e não a consegue encontrar.

b) Como o int soma = 0; estaria zerarando a cada volta do ciclo, o programa perderia a conta anterior e guardaria apenas o valor da última volta.

c) Basta declarar a soma antes do ciclo para ela acumular os valores e continuar acessível no fim.
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int soma = 0; // Declarada fora para acumular e ser vista no fim
    
    for (i = 1; i < 10; i++) {
        soma += i * i;
    }
    
    printf("Soma final = %d\n", soma);
    system("PAUSE");
    return 0;
}
