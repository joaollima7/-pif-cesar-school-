a) O compilador emite um erro porque a variável soma foi declarada dentro do bloco do for, o que significa que ela só existe lá dentro. Quando o printf tenta usá-la lá no fim, ela já deixou de existir.

b) As iterações que correm a sério vão de i = 1 até i = 7. O continue no i = 5 faz saltar aquela volta, e o break no i = 8 corta o ciclo logo ali, por isso as voltas 8, 9 e 10 nem chegam a acontecer.

c) #include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int soma = 0;
    for (i = 1; i <= 10; i++) {
        if (i == 5) continue;
        if (i == 8) break;
        soma += i * i;
    }
    printf("Soma final = %d\n", soma);
    system("PAUSE");
    return 0;
}
soma final = 115
